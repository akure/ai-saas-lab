# AI SaaS Lab — Terminal UI (TUI) User Manual

Welcome to the **AI SaaS Lab Terminal UI (TUI)** manual. This client provides a modern, Linux-style terminal interface built with [Charm Bubbletea](https://github.com/charmbracelet/bubbletea) and [Lipgloss](https://github.com/charmbracelet/lipgloss) for testing, interacting with, and monitoring the entire AI SaaS Lab platform.

---

## 1. System Requirements & Platform Support

The TUI client is cross-platform and natively supported on:

- **Linux**: `xterm`, `konsole`, `gnome-terminal`, `alacritty`, `kitty`.
- **macOS**: `Terminal.app`, `iTerm2`, `Warp`.
- **Windows**: `Windows Terminal`, `PowerShell 7+`, `cmd.exe`.

### Prerequisites
- **Go**: Version `1.22.2` or later installed.

---

## 2. Quick Start Guide

### Step 1: Launch the Server Backend
Open your first terminal window and start the AI SaaS Lab server:

```bash
go run ./cmd/lab
```

*Output:*
```text
[lab] listening on :8080 (quota=50 tokens/day)
```

### Step 2: Launch the Terminal UI Client
Open a second terminal window and run:

```bash
go run ./cmd/tui
```

---

## 3. Command Line Flags

You can customize the server URL or start with a specific API key using CLI flags:

```bash
# Connect to custom server port/host
go run ./cmd/tui -server http://localhost:8080

# Start with a specific API key
go run ./cmd/tui -key demo-key-pro

# Combine custom server and API key
go run ./cmd/tui -server http://127.0.0.1:8080 -key demo-key-starter
```

| Flag | Default Value | Description |
| :--- | :--- | :--- |
| `-server` | `http://localhost:8080` | Target AI SaaS Lab server base URL |
| `-key` | `demo-key-pro` | Initial API Key to use for authentication |

## 4. Keybindings Cheat Sheet

### Global Navigation

| Key | Action |
| :--- | :--- |
| `Tab` | Cycle forward through view tabs (`Dashboard` $\rightarrow$ `Chat` $\rightarrow$ `Sessions` $\rightarrow$ `Key Admin`) |
| `1` | Switch directly to **Tab 1: Dashboard** |
| `2` | Switch directly to **Tab 2: Interactive Chat** |
| `3` | Switch directly to **Tab 3: Sessions Manager** |
| `4` | Switch directly to **Tab 4: Key Admin** |
| `Ctrl+C` | Gracefully quit the TUI application |

### Tab 2: Interactive Chat Controls

| Key | Action |
| :--- | :--- |
| `Enter` | Send current prompt / message to AI completion engine |
| `Ctrl+R` | Cycle active Persona mode (`developer` $\rightarrow$ `analyst` $\rightarrow$ `creative` $\rightarrow$ `tutor` $\rightarrow$ `support`) |
| `Ctrl+M` | Toggle Cross-Session Memory Recall (`[Memory: ON]` / `[Memory: OFF]`) |
| `Ctrl+L` | Clear chat viewport transcript |
| `PageUp` / `PageDown` | Scroll chat viewport transcript up/down |

### Tab 3: Sessions Manager Controls

| Key | Action |
| :--- | :--- |
| `↑` / `k` | Move cursor up in sessions list |
| `↓` / `j` | Move cursor down in sessions list |
| `Enter` | Switch active conversation thread to selected session |
| `d` | Delete selected chat session thread |

### Tab 4: Key Admin Controls

| Key | Action |
| :--- | :--- |
| `p` | Issue and activate a new **PRO** plan API key |
| `s` | Issue and activate a new **STARTER** plan API key |

## 5. Tab-by-Tab User Interface Guide

### Tab 1: Dashboard (`[1]`)

The Dashboard view provides a real-time overview of system health and account resource consumption:

- **Server Connection**: Displays connection status (`[ONLINE]`).
- **Active API Key & Plan**: Shows current authenticated key (`demo-key-pro`) and plan badge (`PRO` / `STARTER`).
- **Daily Token Quota Consumption Gauge**: A color-coded progress bar tracking daily token usage:
  - 🟩 **Green** (`0% - 50%`): Safe usage range.
  - 🟨 **Amber** (`50% - 80%`): Moderate usage.
  - 🟥 **Red** (`80% - 100%`): Nearing or at daily token quota limit.
- **Active Settings Summary**: Displays active persona role mode, cross-session memory state, and active session ID.

---

### Tab 2: Interactive Chat (`[2]`)

The Chat view is the core workspace for interacting with AI models:

- **Top Status Bar**: Shows current Persona badge (`[developer]`), Memory recall status, and active Session ID.
- **Transcript Viewport**: Displays real-time streaming tokens generated by the completion provider with colored role badges:
  - `USER`: Cyan
  - `ASSISTANT`: Emerald Green
  - `SYSTEM`: Slate Grey
- **Real-Time SSE Token Streaming**: Tokens stream in real time without locking the user interface.
- **Dynamic Role Mode Switching (`Ctrl+R`)**:
  - `developer`: Formats clean code snippets and dry technical answers.
  - `analyst`: Produces bullet-pointed summaries with zero fluff.
  - `creative`: Product strategy & exploratory ideas.
  - `tutor`: Step-by-step mentor explanations.
  - `support`: Empathetic troubleshooting guidance.
- **Cross-Session Memory Recall (`Ctrl+M`)**: When enabled, automatically searches past conversation threads for this API key and injects recalled context into the AI context.

---

### Tab 3: Chat Sessions Manager (`[3]`)

Manage all active conversation threads:

- **Sessions List**: Browse all sessions owned by your API key.
- **Active Thread Marker (`★`)**: Indicates which conversation thread is currently active.
- **Switch Thread (`Enter`)**: Select any session and press `Enter` to resume that specific conversation thread in Tab 2.
- **Delete Thread (`d`)**: Delete past conversation threads from memory.

---

### Tab 4: Key Admin (`[4]`)

Manage API credentials and issue new keys:

- **Key Metrics**: Inspect total tokens consumed by current API key.
- **Issue PRO Key (`p`)**: Instantly creates a new PRO plan API key (`demo-pro-xxxxxx`) and activates it.
- **Issue STARTER Key (`s`)**: Instantly creates a new STARTER plan API key (`demo-starter-xxxxxx`) and activates it.

## 6. Troubleshooting & FAQs

### Issue: "Server error / Connection refused"
- **Cause**: The backend server is not running on port 8080.
- **Fix**: Run `go run ./cmd/lab` in a separate terminal window before launching `go run ./cmd/tui`.

### Issue: "HTTP 403 Forbidden / Policy Check Failed"
- **Cause**: Your API key has exceeded its daily token quota or is inactive.
- **Fix**: Switch to Tab 4 (`Key Admin`) and press `p` to generate a fresh PRO plan API key.

### Issue: Terminal layout distortion or text overlap
- **Fix**: Resize your terminal window to at least 80 columns by 24 rows. Press `Ctrl+L` in Tab 2 to refresh the viewport.
